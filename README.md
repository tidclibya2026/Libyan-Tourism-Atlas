# Atlas_-landscape

## أطلس ليبيا السياحي — الموارد الطبيعية | V2

نسخة تأسيسية احترافية محسنة لبناء منصة GIS سياحية وطنية قابلة للتدشين الحكومي.

## ما الجديد في V2

- واجهة خريطة أكثر احترافية.
- بحث عام مع اقتراحات فورية.
- فلاتر متعددة.
- بحث داخل نطاق الخريطة الحالي.
- بحث مكاني بالنطاق بالكيلومتر.
- طبقات هرمية ضمن مجموعات رئيسية وفرعية.
- مواقع جذب سياحي مميزة.
- بطاقة معلومات تفصيلية.
- بيانات وصفية كاملة من GeoJSON.
- معرض صور داخل بطاقة الموقع.
- Lightbox لعرض الصور.
- مؤشرات أساسية وحالة تحقق.
- أدوات خريطة: خرائط أساس، كامل ليبيا، موقعي.
- إحداثيات مؤشر الفأرة ومقياس رسم.
- نظام fallback عند تعذر MarkerCluster.

## ملاحظة مؤسسية

الصور تربط بالموقع فقط عندما تكون هوية الملف مرتبطة بالموقع بوضوح. لا ينبغي نسبة صور غير مسماة إلى موقع بعينه دون تحقق.
