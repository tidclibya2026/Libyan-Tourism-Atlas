# V2.5 — تقرير الربط الإحداثي

## نتائج البحث داخل GeoJSON

- جسر وادي الكوف القديم: مطابقة مباشرة.
- بحيرة أم الماء: سجلان متقاربان؛ أضيف «بحيرة أم المام» كمرادف بحثي فقط.
- بحيرة مافو: مطابقة مباشرة.
- عين الدبوسية: سجلان مستقلان بالاسم نفسه.
- شلالات رأس الهلال: لا يوجد اسم مطابق حرفيًا؛ تم ربط مرشح واضح باسم «شلال وادي مرقس» مع وسم Candidate.
- بحيرات الجغبوب: تم توحيد أربع بحيرات تؤكدها دراسة أكاديمية 2025 وربطها بإحداثيات GeoJSON.

## بحيرات الجغبوب الأساسية

1. بحيرة الملفا
2. بحيرة الفريدغة
3. بحيرة العرايشة
4. بحيرة العامرة

## أكبر بحيرة

لم يتم اعتماد «أكبر بحيرة» لأن GeoJSON الحالي يحتوي نقاطًا فقط ولا يحتوي مضلعات أو مساحات.
التحديد الصحيح يحتاج:
- قياس مساحة سطح الماء عبر GIS / صور فضائية، أو
- مرجع فني منشور يحدد المساحة.
