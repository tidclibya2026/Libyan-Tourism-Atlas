# نموذج بيانات مواقع الجذب السياحي المميزة

يستخدم الملف `data/attractions.json` لإثراء نقاط GeoJSON دون تضخيم الملف الجغرافي الرئيسي.

## الحقول المقترحة

- `id`
- `geojson_name`
- `name_ar`
- `name_en`
- `category`
- `importance_level`
- `is_featured`
- `description_ar`
- `location`
- `metrics`
- `images`
- `tourism_values`
- `verification`
- `sources`

تُضاف البيانات فقط بعد المراجعة والتحقق الفني.
