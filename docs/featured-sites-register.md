# سجل المواقع السياحية الطبيعية المميزة — V2.3

- إجمالي المواقع: **17**
- مرتبطة مكانيًا مبدئيًا: **9**
- بانتظار الربط اليدوي: **8**

## سياسة الربط

- `exact`: مطابقة مباشرة بالاسم أو معرف السجل.
- `alias`: مطابقة باسم بديل معتمد.
- `manual`: يمنع الربط التلقائي حتى يتم تحديد السجل الصحيح.

## المواقع

1. **بحيرة قبر عون** — البحيرات الطبيعية والصحراوية — `exact` / `matched`
2. **واو الناموس** — البحيرات الطبيعية والصحراوية — `exact` / `matched`

9. **عين الفرس – غدامس** — العيون الطبيعية — `alias` / `matched`
